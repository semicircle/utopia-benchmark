# Reslil workspace

You will write programs in **Reslil**, a programming language you have not
seen before. Learn it from the reference, then solve the tasks.

- Language reference: `docs/reslil-reference.md`
- Toolchain: `bin/reslil run FILE.res` runs a program; `bin/reslil check FILE.res` only checks it.
- Tasks: one file per task in `tasks/`.
- Put your solution to `tasks/ID.md` in `solutions/ID.res`.

Programs read standard input and write standard output. Your solutions are
graded by running them on hidden test inputs and comparing the output
exactly.
