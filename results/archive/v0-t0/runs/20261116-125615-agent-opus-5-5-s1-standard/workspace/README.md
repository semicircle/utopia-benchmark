# Wochu workspace

You will write programs in **Wochu**, a programming language you have not
seen before. Learn it from the reference, then solve the tasks.

- Language reference: `docs/wochu-reference.md`
- Toolchain: `bin/wochu run FILE.woc` runs a program; `bin/wochu check FILE.woc` only checks it.
- Tasks: one file per task in `tasks/`.
- Put your solution to `tasks/ID.md` in `solutions/ID.woc`.

Programs read standard input and write standard output. Your solutions are
graded by running them on hidden test inputs and comparing the output
exactly.
