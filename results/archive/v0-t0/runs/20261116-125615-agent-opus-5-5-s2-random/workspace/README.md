# Gutrur workspace

You will write programs in **Gutrur**, a programming language you have not
seen before. Learn it from the reference, then solve the tasks.

- Language reference: `docs/gutrur-reference.md`
- Toolchain: `bin/gutrur run FILE.gut` runs a program; `bin/gutrur check FILE.gut` only checks it.
- Tasks: one file per task in `tasks/`.
- Put your solution to `tasks/ID.md` in `solutions/ID.gut`.

Programs read standard input and write standard output. Your solutions are
graded by running them on hidden test inputs and comparing the output
exactly.
