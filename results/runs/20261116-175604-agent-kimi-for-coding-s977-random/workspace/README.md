# Dushpek workspace

You will write programs in **Dushpek**, a programming language you have not
seen before. Learn it from the reference, then solve the tasks.

- Language reference: `docs/dushpek-reference.md`
- Toolchain: `bin/dushpek run FILE.dus` runs a program; `bin/dushpek check FILE.dus` only checks it.
- Tasks: one file per task in `tasks/`.
- Put your solution to `tasks/ID.md` in `solutions/ID.dus`.

Programs read standard input and write standard output. Your solutions are
graded by running them on hidden test inputs and comparing the output
exactly.
