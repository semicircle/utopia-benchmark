Utopia

Can your AI code in a language that didn't exist this morning?

Every run of Utopia generates a brand-new programming language from a seed: fresh keywords, its own syntax, and false friends — semantics that look familiar but behave differently (indices from 1, right-to-left operator grouping, switch fallthrough…). The model gets the manual and must write working programs. Nothing it memorized applies.

Findings

Method

  
    
    
  1. Generate. A seed produces a whole language: a conlang lexicon, independent
      syntax styles for functions, conditionals, switches and loops (C-like, Pascal-like, BASIC-like or
      assembly-like), operator spellings, and ten semantic knobs. A reference manual is generated from a
      fixed template, and every example in it is executed to produce the output shown.
    2. 
    
  2. One-shot mode. The model receives the manual and all tasks in one prompt, with no
      tools, and must write every solution without running anything. It is cheap and measures pure
      in-context learning.
    3. 
    
  3. Agent mode. The model works as a coding agent (Claude Code, headless) in a fresh
      workspace with the manual, the tasks and the language's toolchain, and may experiment freely.
      Web access is disabled, the workspace sits outside the benchmark's source tree, and every file
      path and shell command in the transcript is audited for attempts to look elsewhere.
    4. 
    
  4. Grade. Solutions run against hidden tests; a task passes only if every test's
      output matches exactly.
    5. 
  

  
v0 caveats: only seven T0 tasks (small programs), public practice seeds, few runs per
    arm, so differences of one task are noise. Models are driven through the claude CLI;
    other providers are not wired up yet.
